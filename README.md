# img-pub

画像共有用の **Public** リポジトリ。Claude などの外部ツールから URL で読み込めるようにするための置き場。

## ★ Public リポジトリ ＝ 世界中から見える

このリポジトリに置いたファイルは、**GitHub アカウントを持たない誰からでも閲覧・ダウンロードできる**。
置く前に必ず「これは世に出て困らないか？」を確認すること。

## 置いていいもの

- Kindle の図版・表紙（どうせ本として公開される素材）
- ブログのアイキャッチ・記事内画像（どうせ記事で公開される素材）

判断基準：**「どうせ公開される素材」かどうか。**

## ★ 置いてはいけないもの

- **スクリーンショット**（PC ユーザー名・フォルダパスが写り込むため）
- 未公開素材（発売前の表紙、下書き段階の図など）
- 個人情報が写り込んだ画像

→ これらは **Private リポジトリの [img-lab](https://github.com/wii4021/img-lab) へ。**

## 構成

```
img-pub/
└── kindle/
    └── book-06/   #06 の図版
```

## 命名

英語ハイフン／アンダースコア区切り（例: `ch1_fig_pricing.png`）
